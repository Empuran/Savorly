# Savorly

A cooking application interface.

## Quick Start

1. Install [Node.js](https://nodejs.org/) (required).
2. Run `cooking-app-interface/start_app.bat`.
3. The script will automatically install dependencies and start the application.

## Development

The project is built with Next.js. To run manually:

```bash
cd cooking-app-interface
npm install
npm run dev
```

## Publishing

### Web Deployment
The easiest way to publish is to deploy to a platform like [Vercel](https://vercel.com/) or [Netlify](https://www.netlify.com/). Connect your GitHub repository, and the build settings will be automatically detected.

### Desktop Application
To package this as a standalone desktop application (e.g., .exe), consider using [Electron](https://www.electronjs.org/) or [Tauri](https://tauri.app/).
